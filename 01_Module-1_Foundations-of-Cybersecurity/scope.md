# Scope - Google Cybersecurity Portfolio

## Objective

Build an evidence-based portfolio from the Google Cybersecurity Professional Certificate that documents the concepts I learned and connects them with practical cybersecurity work.

The repository is intended to show understanding, application, and technical growth rather than reproduce course material.

---

## Portfolio Approach

Each module may include:

- a short README explaining the main concepts
- practical notes or deliverables
- selected screenshots or outputs when they add useful evidence
- links to related TryHackMe practice where relevant

Evidence is selected based on technical value rather than a fixed screenshot count.

---

## Evidence Policy

I only include evidence that demonstrates useful work, such as:

- commands or queries I executed
- security analysis or findings
- structured risk assessments
- network or system observations
- scripts and their outputs
- incident-response documentation

Course slides, repetitive screenshots, and content that does not demonstrate my own work are not included.

---

## Repository Goals

By the end of the portfolio, the repository should demonstrate practical foundations in:

- cybersecurity fundamentals
- security risk management
- network security
- Linux and SQL
- assets, threats, and vulnerabilities
- detection and incident response
- Python security automation
- professional cybersecurity workflows

The final integrated security case will connect concepts from multiple modules into one end-to-end scenario.
