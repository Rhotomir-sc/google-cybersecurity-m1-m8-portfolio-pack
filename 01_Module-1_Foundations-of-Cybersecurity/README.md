## Overview

This module introduced the foundations of cybersecurity and helped me understand how security teams protect people, systems, networks, and data.

I focused on building the basic vocabulary and mindset needed for later technical work.

Rather than treating cybersecurity as only a collection of tools, I learned to think about security in terms of:

- assets
- threats
- vulnerabilities
- risks
- controls
- business impact

---

## Key Concepts

### Security Goals

One of the core ideas was protecting:

```text
Confidentiality
Integrity
Availability
```

These principles provide a simple way to think about what security controls are trying to protect.

### Threats, Vulnerabilities, and Risks

I learned to distinguish between:

```text
Threat
→ something that can cause harm

Vulnerability
→ a weakness that can be exploited

Risk
→ the potential impact and likelihood of that threat exploiting the weakness
```

This distinction became important in later modules when analysing security controls and incidents.

### Security Controls

Security controls can reduce risk through different approaches.

Examples include:

```text
Access controls
Network controls
Monitoring
Policies
Authentication
Incident response
```

Later modules in this repository apply these ideas in more practical scenarios.

### Security Domains

The module also introduced the broad areas that security professionals may work across, including:

```text
Security operations
Network security
Identity and access management
Risk management
Asset security
Security engineering
Incident response
```

This helped me understand how different technical and non-technical areas connect.

---

## Security Mindset

A major lesson from this module was that security decisions should be based on evidence and risk rather than assumptions.

My general approach is:

```text
Identify the asset
       ↓
Understand the threat
       ↓
Identify weaknesses
       ↓
Evaluate the risk
       ↓
Apply controls
       ↓
Monitor the result
```

I continue using this approach throughout the rest of the portfolio.
