# Professional Approach

While building this portfolio, I tried to follow several principles.

## Evidence Over Claims

Instead of writing:

```text
I know Python.
```

I prefer to show:

```text
Working Python security scripts
+
Verified output
```

Instead of writing:

```text
I understand incident response.
```

I prefer to show:

```text
Investigation
+
Indicators
+
Containment
+
Eradication
+
Recovery
```

---

## Clear Documentation

Technical findings should be understandable to someone who did not perform the original investigation.

I therefore try to document:

```text
What I observed
What I did
What I found
What I can prove
What still requires verification
```

# What I Learned

The main lesson from this final module was that technical knowledge becomes more valuable when it can be demonstrated clearly.

A strong portfolio should answer:

```text
What did I learn?
What did I actually do?
What evidence do I have?
What did I conclude?
```
